# Kinasato vil.

情シス（コーポレートITエンジニア）鬼無里 餅衛門のポートフォリオサイトです。
スキル・経歴・アウトプットなどをまとめています。

https://kinasato.github.io/

## 特徴

- [デジタル庁デザインシステム](https://design.digital.go.jp/dads/)（DADS）に沿った、アクセシビリティに配慮したデザイン
- ダークモード対応（OSの設定に追従、手動切り替えも可能）
- PC・スマートフォンに対応したレスポンシブデザイン
- HTML / CSS / JavaScript のみで構成した静的サイト（GitHub Pages で公開）
